K-Nearest Neighbours

Discover how machines classify data by finding the nearest examples. Learn the mathematical formula, understand the algorithm, run simple Python code and explore real-world uses.

Start Learning ↓

01. Introduction

K-Nearest Neighbours (KNN) is a supervised machine learning algorithm used for classification and regression. It predicts an outcome by examining the closest data points in a dataset.

For example, a system can classify a fruit as an apple or an orange using features such as weight and sweetness.

Key idea: Similar data points are expected to have similar outcomes. KNN uses nearby examples to make a prediction.

02. Description and Working

How does KNN work?

  1. Collect a dataset containing features and known labels.
  2. Choose K, the number of neighbours to consider.
  3. Calculate the distance from the new data point to the training points.
  4. Select the K closest neighbours.
  5. For classification, choose the most common class among those neighbours.
Example: If K = 3 and two of the three nearest neighbours are apples, the model predicts an apple.

03. Mathematical Formula

Euclidean Distance

KNN commonly uses Euclidean distance to measure the distance between two data points.

d = √[(x₂ − x₁)² + (y₂ − y₁)²]

Where:

  • (x₁, y₁): First data point.
  • (x₂, y₂): Second data point.
  • d: Distance between the points.

Step-by-Step Calculation

Suppose the points are A = (2, 3) and B = (5, 7).

d = √[(5 − 2)² + (7 − 3)²]

d = √[3² + 4²]

d = √25 = 5

The distance between A and B is 5 units. KNN calculates distances like this to find the nearest neighbours.

Choosing K

Predicted class = Majority class among K nearest neighbours

A small K can be sensitive to noise. A larger K can smooth predictions but may overlook local patterns. The best value should be selected using validation data.

04. Python Implementation

This example uses a small fruit dataset with two features: weight in grams and sweetness on a scale of 1 to 10.

Short and Simple Python Code

import pandas as pd
from sklearn.neighbors import KNeighborsClassifier

# Fruit dataset: weight and sweetness
data = pd.DataFrame({
    "Weight": [150, 160, 170, 120, 130, 140],
    "Sweetness": [7, 8, 7, 3, 4, 3],
    "Fruit": ["Apple", "Apple", "Apple",
              "Orange", "Orange", "Orange"]
})

X = data[["Weight", "Sweetness"]]
y = data["Fruit"]

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X, y)

new_fruit = [[155, 7]]
print("Predicted fruit:", model.predict(new_fruit)[0])

Code Explanation

CodePurpose
pd.DataFrame()Creates the dataset.
KNeighborsClassifier()Creates the KNN classification model.
n_neighbors=3Uses the three nearest neighbours.
model.fit()Stores the training examples for neighbour search.
model.predict()Predicts the fruit category.
To run: Install the libraries using pip install pandas scikit-learn. Run the code in Google Colab, Jupyter Notebook or Python.

Important: This is a tiny illustrative dataset. Real projects should use more data and evaluate performance on separate test data. Because weight and sweetness have different scales, feature scaling is often important when using KNN.

06. Real-World Applications

1. Healthcare

Helps classify cases by comparing patient features with similar records.

2. Recommendation Systems

Finds similar users or items using their numerical features.

3. Banking

Can help classify transactions or customer profiles based on historical examples.

4. Image Recognition

Classifies images using numerical representations of their features.

5. Agriculture

Can help classify plants or fruit using measured characteristics.

KNN is simple to understand, but prediction can become slower with very large datasets. It is also sensitive to irrelevant features, feature scales and the choice of K.

07. Conclusion

K-Nearest Neighbours is a supervised machine learning algorithm that predicts outcomes by examining the closest training examples. It can be used for both classification and regression.

Its mathematical foundation is easy to understand, making it a useful starting point for learning classification, distance calculations and practical machine learning.
